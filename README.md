## 🎯 About

Stayora is a comprehensive hotel booking platform that allows users to discover, book, and manage property rentals. Built with modern web technologies and featuring an intelligent recommendation system, Stayora provides a seamless experience for both guests and property hosts.

### Why Stayora?

- 🤖 **AI-Powered Recommendations** - Smart property suggestions based on user preferences
- 📱 **Fully Responsive** - Works flawlessly on desktop, tablet, and mobile devices
- ⚡ **Fast & Lightweight** - Optimized performance with minimal dependencies
- 🎨 **Modern UI/UX** - Clean, intuitive interface inspired by industry leaders
- 🔒 **Secure** - Built with security best practices

## ✨ Features

### For Guests

- 🏡 **Browse Properties** - Explore a wide range of available accommodations
- 🔍 **Smart Search** - Filter properties by location, price, and rating
- ❤️ **Favorites Su love for later
- 📅 **Easy Booking** - Simple booking process with date selection
- 🤖 **Personalized Recommendations** - Get property suggestions tailored to your preferences

- ✏️ **Edit Listings** - Update property details anytime

## 📦 Installation

### Prerequisites

Before you begin, ensure you have the following installed:
- **Node.js** (v14.0.0 or higher)
- **npm** (v6.0.0 or higher)
- **Git**

### Step-by-Step Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/stayora.git
   cd stayora
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up environment variables**
   ```bash
   cp .env.example .env
   ```
   
   Edit `.env` file:
   ```env
   PORT=3000
   NODE_ENV=development
   ```

4. **Build Tailwind CSS**
   ```bash
   npm run build
   ```

5. **Start the development server**
   ```bash
   npm run dev
   ```

6. **Open your browser**
   
   Navigate to `http://localhost:3000`
